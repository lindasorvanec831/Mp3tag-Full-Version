## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Edit and Save Tags** — Easily recognize, edit, and save metadata for all your audio files.
- **Generate Playlists** — Create playlists with just a few clicks based on your tagged files.
- **Tag Transformation** — Seamlessly transform tags into file names or vice-versa for better organization.
- **Multiple Tag Sources** — Access various sources like freedb, Amazon, Cover Art, discogs, and MusicBrainz for accurate metadata.
- **Extensive Format Support** — Full support for ID3v1, ID3v2.3, ID3v2.4, iTunes MP4, WMA, APEv2 Tags, and Vorbis Comments.
